# Frontend Experience Matrix

| Concern | Required decisions and evidence |
|---|---|
| Responsive | breakpoints/conditions, layout/content priority, overflow, orientation, zoom/reflow, touch/keyboard behavior |
| UI states | loading, empty, partial, validation, disabled, unauthorized, offline, timeout, error, retry, recovered |
| Accessibility | semantics, name/role/value, keyboard, focus, announcements, contrast, zoom/reflow, reduced motion, assistive-tech scope |
| Localization | locales/fallback, message ownership, plural/interpolation, date/time/number/currency/timezone, expansion, RTL, translated assets |
| Theme/motion | tokens/themes, contrast modes, motion purpose/cancellation, reduced-motion alternative |
| Support | browser/device/viewport/input matrix, evidence, unsupported behavior and fallback |
| Privacy | consent, analytics, experiments, personalization, data minimization, opt-out/failure behavior |

Every material requirement maps to a route/component owner and UI/visual/accessibility/compatibility evidence. Unsupported combinations and manual-review obligations remain visible.
