# RabbitMQ Reference

Model exchanges, bindings, routing keys, queues, acknowledgements, prefetch, TTL, dead-letter exchanges, and publisher confirms. Choose direct, topic, fanout, or headers routing from the delivery requirement. Bound prefetch and queue growth, and define behavior for NACK/requeue, consumer failure, broker failure, and poison messages. Monitor queue depth, message age, unacked messages, publish confirms, connections, and DLX traffic.
